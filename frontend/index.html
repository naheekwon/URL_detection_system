정밀한 다중 클래스 탐지

Phishing

피싱 사이트 차단

사용자의 개인정보나 금융 정보를 탈취하기 위해 정교하게 위조된 로그인 페이지 및 가짜 웹사이트를 머신러닝으로 즉각 식별합니다.

Malware

악성코드 유포지 탐지

랜섬웨어, 트로이 목마 등 악성 스크립트가 숨겨져 있거나 자동으로 다운로드를 유발하는 위험한 엔드포인트를 사전에 탐지합니다.

Safe Browsing

안전한 브라우징 보장

정상적이고 안전한 URL은 신속하게 통과시켜 업무 지연을 방지하며, 분석 결과를 통해 사용자가 클릭 전 위험 여부를 판단할 수 있도록 돕습니다.

About LinkWatcher

LinkWatcher는 사용자가 의심스러운 URL을 클릭하기 전에 위험 여부를 확인할 수 있도록 설계된 AI 기반 URL 탐지 웹서비스입니다. 피싱, 악성코드, 스팸성 URL과 같은 웹 기반 보안 위협을 분석하고, 사용자가 보다 안전하게 웹 환경을 이용할 수 있도록 지원합니다.

Purpose 클릭 전 URL 위험도 확인
Target 피싱, 악성코드, 스팸, 정상 URL
Project Type 졸업작품 및 AI 보안 학과 프로젝트

Detection Model

LinkWatcher의 탐지 모델은 URL 문자열에서 추출한 토큰, 도메인 구조, 경로 패턴, 의심 키워드 등의 특징을 기반으로 URL을 다중 클래스로 분류합니다. 단순히 안전/위험 여부만 출력하는 것이 아니라, 피싱, 악성코드, 스팸, 정상 URL과 같이 구체적인 위협 유형을 구분하는 것을 목표로 합니다.

Multiclass Classification Benign, Phishing, Malware, Spam URL 분류
Risk Token Analysis URL 내 위험 토큰과 의심 패턴 분석
Explainable Output 탐지 결과와 함께 판단 근거 제공

Model Architecture

아래 구조도는 URL 입력부터 특징 추출, 다중 클래스 분류, 위험 토큰 기반 설명 출력까지 이어지는 LinkWatcher의 전체 분석 흐름을 나타냅니다.
