정밀한 다중 클래스 탐지

Phishing

피싱 URL 위험 분석

URL 구조, 도메인 패턴, 위험 토큰과 모델 예측 결과를 함께 분석해 피싱 가능성이 높은 주소를 분류하고 판단 근거를 제공합니다.

Malware

악성 URL 유형 분류

학습된 URL 특징을 기반으로 malware, defacement 등 악성 유형 가능성을 분류하고, 위험 판단에 영향을 준 주요 신호를 설명합니다.

Benign Check

정상 URL 판별 지원

정상으로 판단된 URL은 benign 결과와 신뢰도, 설명 정보를 함께 제공해 사용자가 접속 전 위험 수준을 참고할 수 있도록 돕습니다.

About LinkWatcher

LinkWatcher는 사용자가 의심스러운 URL을 클릭하기 전에 위험 여부를 확인할 수 있도록 설계된 AI 기반 URL 탐지 웹서비스입니다. 피싱, 악성코드 유포, 디페이스먼트 URL과 같은 웹 기반 보안 위협을 분석하고, 사용자가 보다 안전하게 웹 환경을 이용할 수 있도록 지원합니다.

Purpose 클릭 전 URL 위험도 확인
Target 피싱, 악성코드, 디페이스먼트, 정상 URL
Project Type AI 기반 URL 탐지 프로젝트

Detection Model

LinkWatcher의 탐지 모델은 URL 문자열에서 추출한 토큰, 도메인 구조, 경로 패턴, 의심 키워드 등의 특징을 기반으로 URL을 다중 클래스로 분류합니다. 단순히 안전/위험 여부만 출력하는 것이 아니라, 피싱, 악성코드, 디페이스먼트, 정상 URL과 같이 구체적인 위협 유형을 구분하는 것을 목표로 합니다.

Multiclass Classification Benign, Phishing, Malware, Defacement URL 분류
Risk Evidence Fusion 위험 토큰, Transformer 중요도, 정적 페이지 evidence 통합 분석
Explainable Output 토큰·문맥·페이지 근거를 함께 시각화

Model Architecture

아래 구조도는 URL 입력부터 특징 추출, 다중 클래스 분류, 위험 토큰 기반 설명 출력까지 이어지는 LinkWatcher의 전체 분석 흐름을 나타냅니다.
